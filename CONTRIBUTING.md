# Contributing to FluxOptics.jl

Thank you for your interest in FluxOptics.jl!

## Current Contribution Model

FluxOptics.jl is currently a single-maintainer project. While the code is open source (MIT license), the maintainer evaluates and integrates contributions to ensure consistency with the package design and goals.

## How You Can Help

### Bug Reports
If you encounter a bug, please [open an issue](https://github.com/anscoil/FluxOptics.jl/issues) with:
- A minimal reproducible example
- Your Julia version and FluxOptics.jl version
- Expected vs. actual behavior

### Feature Requests
Feature suggestions are welcome! Please [open an issue](https://github.com/anscoil/FluxOptics.jl/issues) describing:
- Your use case
- Why existing functionality doesn't address it
- Any relevant references or examples

### Use Cases and Examples
Real-world use cases are especially valuable for:
- Improving documentation with practical examples
- Identifying missing features
- Validating design decisions

If you've used FluxOptics.jl for an interesting application, consider sharing it as an issue or discussion.

## Code Contributions

At this stage, **please open an issue before submitting code**. This allows discussion of:
- Whether the feature aligns with the package design
- Implementation approach
- Integration strategy

Small bug fixes and documentation improvements are welcome as pull requests.

## Questions?

For questions about using FluxOptics.jl, please open an [issue](https://github.com/anscoil/FluxOptics.jl/issues) with the "question" label.
